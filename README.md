# PSH Play Feedback Test

This is a small Streamlit prototype for testing uploaded play feedback.

In Streamlit Community Cloud, add these secrets under the app's settings:

```toml
OPENAI_API_KEY = "your-key"
APP_PASSWORD = "choose-a-test-password"
```

The app accepts PDF, DOCX, TXT, and Markdown files. Do not put secrets in this repository.
